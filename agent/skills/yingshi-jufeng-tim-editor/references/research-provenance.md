# 公开研究：证据边界与来源

研究完成于 2026-09-24。用于该 skill 的原则：**公开资料支持的事实可以引用；具体风格规则只有在逐帧样本分析或可靠一手署名支持时，才归因给个人。**

## 可核验事实（有限范围）

1. 影视飓风的公开工作流分享把内容生产分为组织架构、编导、拍摄和后期，支持“把成片视作跨环节流程”这一结论；不证明任一历史流程仍是当前唯一标准。
   - https://www.bilibili.com/video/BV13QzbYuEWr/
   - https://www.bilibili.com/video/BV1NR4y1G7TM/
2. 该频道公开发布过 DaVinci Resolve 学习内容，且曾展示过以 iPad Pro 剪辑某一期视频的实践；这不证明它们是所有项目的固定工具链。
   - https://www.bilibili.com/video/BV1B7411A7M1/
   - https://www.bilibili.com/video/BV1qK411H7Vk/
3. 有公开视频页面介绍影视飓风的内容生产和项目管理经验，以及飞书项目在视频制作/项目管理中的应用；支持版本、资产、协作和复盘的流程意识。
   - https://www.bilibili.com/video/BV1Cp421Q7t6/
4. 官方课程宣传强调“系统建立成片能力”和“有质感的成片”，可视为其面向学习者的公开表达，但属于课程营销主张，不等于独立证明效果。
   - https://www.bilibili.com/video/BV16iGi6qEMw/

## 不能确定的内容

现有经核验资料**没有**可靠地证明：

- TIM 的完整身份、职位、任职期间或可核验的主剪作品清单；
- 任何具体字体、色彩空间、响度目标、合成软件、封面模板或剪辑节奏为 TIM 的个人既定规范；
- 具体转场密度、字幕密度、镜头时长等为频道的统一标准。

因此 skill 中的节奏、转场、声音、图形、字幕、调色、封面和合成建议，均是对该内容方向的**可执行分析与行业工作法**，不得写成“TIM 就是这样做的”的事实。

## 将来升级证据的路径

若用户提供可分析的公开视频样本，可按节目类型和年份抽取 8–12 支，逐条时间码记录：

- 开场承诺和首次信息回报；
- 镜头时长、A/B-roll 比例、转场种类；
- 字幕密度、字号层级、图形的叙事功能；
- 音乐/音效的进出点、情绪曲线；
- 调色、封面元素和成片目标平台。

样本量充足后再把稳定规律写入本 skill，并明确样本范围与例外。
