# 影视飓风式制作参考手册

本文件是 `yingshi-jufeng-tim-editor` 的执行参考。它将用户项目内的《影视飓风TIM剪辑师手册》和已完成的公开资料研究整理为工作方法。除“公开可核验事实”节外，其余是**适用于此风格方向的专业剪辑准则**，不应表述为 TIM 的已证实个人规范。

## 1. 风格北极星

**视觉即语言：把抽象主张转为可被看见、比较和感受的证据。**

优先顺序：

1. 观众是否迅速明白“为什么要看”；
2. 画面是否让观众自己得出结论；
3. 声音、字幕、图形和调色是否协同服务一个主焦点；
4. 风格是否克制而统一。

## 2. 结构模板

### 科技评测 / 解释型视频

1. 冷开场：结果、异常或高价值画面；
2. 问题：为什么这件事值得关心；
3. 测试/证据：依次增加难度或对比；
4. 解释：用图形、实拍、屏录回答“为什么”；
5. 反例/边界：什么情况下结论不成立；
6. 收束：给出选择建议和一句可记住的结论。

### 直播精华

1. 以最强反应、争议或结果开场；
2. 迅速补齐发生了什么、谁在场、代价是什么；
3. 保留关键来回与因果，不只堆爆点；
4. 以结果/余味结束，必要时导向完整版章节。

### 口播 / Vlog

- A-roll 做逻辑和人味；B-roll 具体化动词、对象和场景。
- 口播没画面时，不要只加无关空镜；用实际操作、屏录、对比、示意图或素材档案承担解释。
- 近、中、远、特写交替为节奏服务；不要为了“高级”强行每句话换镜头。

## 3. 节奏诊断表

| 症状 | 优先修法 | 不应优先做的事 |
|---|---|---|
| 开头不抓人 | 前置结果、代价、反差或问题；删寒暄 | 加更响的音效 |
| 中段掉速 | 压缩重复，增加新证据/对比或段落目标 | 无意义疯狂转场 |
| A-roll 单调 | 用动词驱动的 B-roll、局部推拉、图形解释 | 乱塞库存空镜 |
| 信息很复杂 | 先建立坐标系，再分步骤显现 | 同屏堆满术语 |
| 情绪不够 | 延长反应和环境，留出落点 | 一直强行卡点 |

## 4. 镜头与转场

优先级：逻辑切 > 动作切 > 声音桥 > 图形转场 > 装饰性转场。

- **J-cut**：先让下一场景声音进来，建立期待或连贯思路。
- **L-cut**：让上一句的声音延续到新的画面，使解释不中断。
- **匹配切**：用动作、形状、方向或色彩将两镜头连接。
- **叠化**：用于真实时间流逝、记忆感，或轻微掩饰口播断口；不能变成默认过渡。
- **关键帧动效**：位置、缩放、蒙版、模糊、音量等多个参数应共用清晰的节奏锚点。

## 5. 图形、标注与字幕

### 信息层级

- 一级：主体或一句结论；
- 二级：数字、名称、条件或对比；
- 三级：出处、时间、补充说明。

每个画面最多一个一级焦点。动画遵循“出现有理由、停留够阅读、离开不抢戏”。

### 字幕

- 以语义块断句，关键字不要被挤到下一行。
- 竖版默认避开底部平台控件与发言者脸部；横版默认放底部安全区，但按构图调整。
- 使用高可读字体、明确字重和稳定行距；白字与复杂背景之间用一种足够的分离手段。
- 专名、数字、百分比、单位、引号和英文大小写需单独校验。

## 6. 声音

- 建立 A-roll 人声的连续性后，再铺环境和音乐。
- 用音乐段落而非单个鼓点决定宏观节奏；重要结论前可适度抽音乐留白。
- 同类音效保持少量、统一的质感；不要让 UI 点击声替代叙事。
- 全片导出前从头到尾测响度和真峰值，并依交付平台处理；避免直接复用别人的数值目标。

## 7. 调色和合成

### 调色顺序

1. 正确输入转换/色彩管理；
2. 曝光、白平衡、对比和肤色；
3. 镜头匹配；
4. 局部引导；
5. LUT、胶片颗粒、辉光等风格层。

### 合成验收

逐项检查：物体是否站得住（透视）、边缘是否干净（遮罩）、是否跟随镜头（跟踪）、是否属于同一光线/空间（阴影、反射、色温）、运动是否同一世界（模糊、帧率、颗粒）。

## 8. 封面方向

可选“录制感”方向：深色底、低饱和红色点缀、白色高对比文案、主体被局部框定或标注。但它是视觉语言库，不是每条内容的模板。

每张封面先回答：

- 手机缩略尺寸下，观众第一眼看到什么？
- 这张图制造的是结果、反差、危险、好奇还是身份认同？
- 标题没有重复封面已经表达的内容吗？
- 人物、产品、文字中是否只有一个主角？
